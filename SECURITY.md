# Security Notes

This repository is an educational lab template.

- Use only fictional users, systems, and ticket content.
- Never store passwords, tokens, real personal information, or confidential request details in tickets or screenshots.
- Keep .env out of Git. Rotate any credential that is accidentally exposed.
- The default Compose binding is localhost only. Online deployment requires provider networking and private database settings.
- Remove the osTicket setup directory and set its generated configuration file read-only after installation.
- Keep the operating system, container base image, osTicket release, and database maintained. Check upstream security advisories before public deployment.
- Do not use this lab as a production help desk without a separate security and operational review.
